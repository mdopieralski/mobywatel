# Tailwind CSS instead of CSS modules (2026-10-28)

## Decision

The PWA (`apps/pwa`) and the shared components (`packages/ui`) are styled with **Tailwind CSS 4.3** utility
classes instead of CSS modules. The user asked for it on 2026-10-28. This replaces "CSS modules" in the stack
record (`stack-2026-10-24.md`). Everything else stays.

## What stays the same

- **Tokens are still the only source of values.** `@mobywatel/brand` keeps `tokens.ts` and injects them as CSS
  variables (`themeCss()`). They switch for dark and senior mode. `packages/brand/src/tailwind.css` maps
  Tailwind's theme names onto those variables. So `bg-surface`, `text-lg` and `min-h-target` follow the theme,
  and nothing has two values.
- **No literal colours.** Tailwind's palette is switched off (`--color-*: initial`), so `bg-red-500` doesn't
  exist. The post-edit hook still blocks hex in `apps/`, and that includes `bg-[#…]`.
- **Our base styles, not Tailwind's preflight.** `global.css` keeps its own small reset in `@layer base`, so
  headings, paragraphs and lists look exactly as before. Utilities always win over the base layer.
- The look is unchanged: the rewrite was checked screen by screen against screenshots taken before it.

## How to write styles

| Need                              | Write                                                                                                                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Colour                            | `bg-surface`, `text-text-muted`, `border-border`, `text-accent`, `bg-card-teal`, `outline-focus`. The names are the token names.                                   |
| Type size                         | `text-xs` … `text-3xl` (grows in senior mode). `leading-tight`, `leading-body`. `font-compact` for the Inter Tight labels.                                         |
| Spacing                           | Tailwind's 4 px step is our grid: `p-1`…`p-6` = `--space-1`…`--space-6`, `p-8` = `--space-7` (32 px), `p-12` = `--space-8` (48 px), `p-30` = `--space-9` (120 px). |
| Radius                            | `rounded-sm`, `rounded-md`, `rounded-lg`, `rounded-pill`.                                                                                                          |
| Touch target                      | `min-h-target`, `min-w-target`, `size-target` (48 px, 56 px in senior mode).                                                                                       |
| Any other token or local variable | `min-h-(--header-height)`, `duration-(--duration-base)`, `ease-standard`.                                                                                          |
| Dark / senior / intro             | `dark:`, `senior:`, `intro-done:` match our theme switches (system dark unless the user picked light; `data-senior`; `data-intro-done`).                           |
| States                            | `hover:`, `focus-visible:`, `aria-pressed:`, `aria-current:`, `data-[state=x]:`, `motion-reduce:`, `group`/`peer`.                                                 |
| Odd media queries                 | `max-[72rem]:`, `min-[64rem]:`, `[@media(hover:hover)]:`, `[@container(min-width:36rem)]:` with `@container` on the parent.                                        |
| Children                          | `[&_p]:m-0`, `*:…`.                                                                                                                                                |
| Animations                        | `animate-intro-reveal`, `animate-intro-rise`, `animate-tick-draw`, `animate-brand-dot-blink` (keyframes in `global.css`).                                          |

A class list that several components share lives in a `.ts` file as a string constant (for example
`export const optionClass = '…'`). No `@apply` and no new `.css` files for components. `global.css`,
`compact-font.css` (font faces) and the brand theme are the only stylesheets.
