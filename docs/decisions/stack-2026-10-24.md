# Stack for the mObywatel prototype

## Decision

> Styling changed on 2026-10-28: CSS modules → Tailwind CSS 4 on the same tokens (`tailwind-2026-10-28.md`).

- **Vite + React + TypeScript (strict) PWA** in `apps/pwa`, with `vite-plugin-pwa` (Workbox) for the manifest,
  precache and update prompt.
- **pnpm workspaces + Turborepo** monorepo: `apps/*`, `packages/*` (`core`, `content`, `brand`, `ui`),
  following City Turfer's layout so agents and skills carry over.
- **Vercel** hosting: a static build, plus an optional serverless function for the LLM proxy.
- **Tests:** Vitest + Testing Library, Playwright + `@axe-core/playwright` on phone viewports, and
  `node --test` for repo tools.

## Why

- The entry is judged by opening a link on a phone, with no login. A client-only PWA loads fast, works offline
  after the first visit, can be installed, and needs no backend for the scripted demo.
- We chose Vite over Next.js because server rendering adds nothing to a no-login prototype, and service worker
  and offline setup is simpler in a plain SPA.
- A monorepo keeps the domain (matters, reminders, the assistant engine) in pure TS packages that are
  unit-tested without React, and leaves room for a website or API later.

## Settled at scaffold time (2026-10-24, versions checked with `pnpm view`)

- **TypeScript pinned to `~6.0.3` repo-wide.** TypeScript 7 (the Go port) was the latest release, but
  `typescript-eslint` 8.72 supports `<6.1.0` only. One compiler for every workspace beats a split.
- **Lint: oxlint** (it ships with the Vite 9 template), with no ESLint for now. If we add ESLint plugins later
  (e.g. jsx-a11y), check the TS range first.
- **Versions:** Vite 8.3, `@vitejs/plugin-react` 6.1, `vite-plugin-pwa` 2.0 (`registerType: 'prompt'`, API
  unchanged from 1.x), React 19.3, React Router 8.5 (`createBrowserRouter` + `RouterProvider` from
  `react-router`), `use-intl` 4.14 (ICU, same syntax as City Turfer), Vitest 5, Playwright 1.64 +
  `@axe-core/playwright` 4.14.
- **Packages are source-only TS** (`exports: ./src/index.ts`, no build step). The app bundles them. Exception:
  `apps/pwa/vite.config.ts` imports `packages/brand/src` by **relative path**. Vite leaves workspace packages
  external when it loads its config, and Node 22.15 cannot load `.ts`.
- **App shell layout:** the header and bottom nav are fixed and only `<main>` scrolls. With a sticky nav,
  content could be hidden behind it (axe target-size, WCAG 2.4.11 Focus Not Obscured).
- **No "ready offline" toast:** on every first visit it covered content. The update prompt stays.
  `<html data-offline-ready>` marks the state for tests.
- **Icons:** our own check-mark mark (`public/icons/favicon.svg`). PNGs come from
  `pnpm --filter @mobywatel/pwa run icons` (`@vite-pwa/assets-generator`).
